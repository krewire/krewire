Architecture & Philosophy

Go-First. Progressive. Zero Bloat.

Built for engineers who value compilation speed, predictable deployments, and maintainable software architecture.

◈

Pure Go Toolchain

No Node.js, no npm dependencies, and no bundler configuration. Your entire application compiles with standard Go tooling into clean, self-contained binaries.

◧

Scoped .kiw Components

Combines YAML frontmatter, standard Go HTML templates, and scoped <style> blocks. CSS classes never leak outside their component boundary.

Progressive Scaling

Enterprise Resilience

Scoping

Why Scoped CSS in Go?

Every .kiw component receives automatic data-kiw-component scope hashing at build time. No CSS collisions, no naming gymnastics, zero runtime cost.

  • ✓ Scoped by Default: Styles remain strictly isolated to the component.
  • ✓ Global CSS via :root: Theme tokens cascade cleanly across layouts.
  • ✓ No Bundler Required: Built directly by the Go compiler without npm.
  • ✓ Light & Dark Mode: Native token switching via data-theme.
