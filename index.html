How it works

Three commands. Zero toolchain.

1

kiw new

Scaffold a site, book, app or cli in seconds.

kiw new my-site --site
cd my-site
2

kiw build

Build static or binary. Scoped CSS, file-based routing, no config.

kiw build
# → .krewire/build/
3

kiw deploy

Deploy to GitHub Pages or your infra. One command.

kiw deploy --target gh-pages

Go-first. Progressive. Zero bloat.

Why scoped CSS?

Every .kiw component gets data-kiw-component scoping automatically. Like Svelte/Astro — zero setup, zero leaks.

  • ✓ Scoped by default
  • ✓ Global via :root
  • ✓ Theme with ui.Theme
