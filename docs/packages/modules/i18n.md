# `i18n`

Import: `github.com/krewire/krewire/packages/i18n`

## Purpose

Internationalization and localization engine: message bundle loading (JSON), translation with variable interpolation, pluralization rules, and HTTP locale detection middleware.

## Main API

- `i18n.NewBundle(opts)`: Initializes a message translation catalog.
- `bundle.LoadLocale(locale, data)`: Loads key-value message dictionaries.
- `i18n.T(ctx, key, args...)`: Localizes a message key using the active request context.
- `i18n.Middleware(bundle)`: HTTP middleware detecting preferred locale from URL prefixes (`/en/`, `/id/`), cookies, or `Accept-Language` headers.

## Example

```go
package main

import (
	"context"
	"fmt"
	"github.com/krewire/krewire/packages/i18n"
)

func main() {
	b := i18n.NewBundle(i18n.WithDefaultLocale("en"), i18n.WithFallbackLocale("en"))
	b.LoadLocale("id", map[string]string{
		"welcome": "Selamat datang, {name}!",
	})

	ctx := i18n.WithLocale(context.Background(), "id")
	msg := i18n.T(ctx, "welcome", map[string]string{"name": "Budi"})
	fmt.Println(msg) // Output: Selamat datang, Budi!
}
```

## Design boundary

Independent domain package. Zero coupling to external translation services.
