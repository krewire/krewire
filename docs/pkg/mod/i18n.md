# `i18n`

Import: `github.com/krewire/krewire/pkg/i18n`

## Purpose

Internationalization and localization engine: message bundle loading (JSON), translation with variable interpolation, pluralization, and HTTP locale-detection middleware.

## Main API

- `i18n.New(fsys fs.FS, opts ...Option) (*Bundle, error)`: Creates a bundle. When `fsys` is non-nil, `lang/` is loaded immediately; pass `nil` to add translations in memory.
- `i18n.NewFromConfig(fsys, cfg, opts...)`: Same, seeded from a `Config`.
- `(*Bundle).AddTranslation(locale, filename string, data map[string]any)`: Adds an in-memory dictionary. An empty `filename` stores it as `<locale>.json`.
- `(*Bundle).Load() error`: Loads every `lang/**/*.json` from the bundle filesystem.
- `(*Bundle).T(ctx, key, args...) string`: Translates using the locale carried in the context.
- `(*Bundle).Translate(locale, key, args...) string`: Translates for an explicit locale; returns the key itself when missing.
- `(*Bundle).ForLocale(locale) *Translator` / `i18n.NewTranslator(bundle, locale)`: Locale-bound translator.
- `(*Bundle).Has(locale, key)` / `HasLocale(locale)` / `Locales()`: Introspection.
- `i18n.Middleware(bundle, opts...)`: Resolves the locale from the `lang` query parameter, the `lang` cookie, then `Accept-Language`; configurable with `WithQueryParam`, `WithCookieName`, `WithHeaderName`.
- `i18n.WithLocale(ctx, locale)` / `i18n.Locale(ctx)`: Context helpers.
- Options: `WithDefaultLocale`, `WithFallbackLocale`, `WithBasePath`, `WithConfig`.

### Interpolation and pluralization

Placeholders accept `{key}`, `{{key}}`, and `:key` forms; parameters are passed as a `map[string]any`/`map[string]string` or as alternating key/value arguments. Plural forms are either a pipe-separated string (`"No items|One item|{count} items"`) or a map with `zero`/`one`/`other` keys, selected from the `count` parameter.

## Example

```go
package main

import (
	"context"
	"fmt"

	"github.com/krewire/krewire/pkg/i18n"
)

func main() {
	b, err := i18n.New(nil, i18n.WithDefaultLocale("en"), i18n.WithFallbackLocale("en"))
	if err != nil {
		panic(err)
	}

	b.AddTranslation("id", "", map[string]any{
		"welcome": "Selamat datang, {name}!",
	})

	ctx := i18n.WithLocale(context.Background(), "id")
	fmt.Println(b.T(ctx, "welcome", map[string]string{"name": "Budi"}))
	// Output: Selamat datang, Budi!
}
```

## Design boundary

Independent domain package. Zero coupling to external translation services.
